   * **Description**: Get historical daily climate data for any location on Earth using the Open-Meteo Climate Change API. Returns daily temperature, precipitation, wind, humidity, and other variables from climate reanalysis models (ERA5, EC-Earth3P\_HR, CMIP6). Data available from 1950 onwards. No authentication required. Useful for climate research, trend analysis, and historical weather studies.
