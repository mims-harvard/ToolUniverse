     Alias for gene. Gene symbol (e.g., 'TP53', 'BRCA1').

   * ``variant_name`` (string) (optional)
     Specific variant name to filter within a gene (e.g., 'L858R', 'V600E', 'T790M'). Use together with gene\_name — CIViC stores variants without the gene prefix (use 'L858R' not 'EGFR L858R').
