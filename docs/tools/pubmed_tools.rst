   * ``limit`` (integer) (optional)
     Number of articles to return. This sets the maximum number of articles retrieved from PubMed (max: 200).

   * ``mindate`` (string) (optional)

   * ``maxdate`` (string) (optional)
     Maximum date for results (format: YYYY/MM/DD or YYYY). Requires datetype to be set.

   * ``datetype`` (string) (optional)

     If true, best-effort fetches abstracts via efetch (adds abstract/abstract\_source fields).

   * ``sort`` (string) (optional)
     Sort order for results. Valid values: 'pub\_date' (newest first), 'Author' (alphabetical by first author), 'JournalName' (alphabetical by journal), 'relevance' (default PubMed ranking).
