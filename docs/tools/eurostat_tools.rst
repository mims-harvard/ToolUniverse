   * **Description**: Retrieve statistical data from Eurostat (EU statistical office) for a specific dataset and filter combination. Eurostat provides 10,000+ datasets covering EU member states for economics (GDP, inflation, trade), social statistics (population, employment, poverty), health, environment, agriculture, and more. Returns time-series values with dimension metadata. Common datasets: 'demo\_pjan' (population by age/sex), 'nama\_10\_gdp' (GDP), 'ilc\_li01' (poverty rate), 'env\_air\_gge' (GHG emissions), 'hlth\_ehis\_fv3e' (health).
