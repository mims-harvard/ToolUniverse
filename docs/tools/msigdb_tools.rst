   * **Description**: Retrieve a Hallmark gene set from MSigDB. The Hallmark collection (H) contains 50 gene sets representing well-defined biological states and processes with coherent expression, distilled from multiple founder sets. These are the most commonly used gene sets for pathway analysis and GSEA. Hallmark gene set names are prefixed with 'HALLMARK\_' followed by the pathway name in uppercase with underscores (e.g., HALLMARK\_APOPTOSIS, HALLMARK\_HYPOXIA, HALLMARK\_P53\_PATHWAY, HALLMARK\_INFLAMMATORY\_RESPONSE, HALLMARK\_EPITHELIAL\_MESENCHYMAL\_TRANSITION).
